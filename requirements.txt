# Pinned, because an unpinned dependency makes a corpus unreproducible: a
# different sentence-transformers or torch can change the embeddings, and the
# whole project is a comparison against exact nearest neighbours.
#
#   python -m pip install -r requirements.txt
#
# No API key is needed for any of this. The embedding model is downloaded once
# (~130 MB) and runs locally, so the ingest, retrieval and every measured
# number work offline after that. `anthropic` is listed last and is OPTIONAL:
# only python/answer.py uses it, and only without --no-llm.

requests==2.31.0              # the Wikipedia API; fetch.py
sentence-transformers==3.0.1  # BAAI/bge-small-en-v1.5; embed.py
torch==2.2.1                  # sentence-transformers backend
#
# The CPU wheel above is correct and sufficient -- every result in this
# repository was produced with the same weights either way. It is just slow:
# measured 11 chunks/second on 8 CPU threads against 357 on an RTX 3050, which
# is ~90 minutes of embedding for the full corpus versus ~3. On an NVIDIA GPU,
# replace the line above with the CUDA wheel and nothing else changes --
# embed.py detects the device:
#
#   python -m pip install --index-url https://download.pytorch.org/whl/cu121 #       "torch==2.2.1+cu121"
#
# EMBED_DEVICE=cpu forces the CPU path if you want to compare.
PyMySQL==1.1.1                # pure-Python MariaDB client; no build step
